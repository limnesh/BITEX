🛠️ Colab troubleshooting and important notes
  • A button doesn't respond? Run the notebook's setup and widget-creation cells, then check that Colab is connected.
  • Missing Qiskit or scikit-learn? Run Setup, which installs the notebook's dependencies.
  • NameError? Restart the runtime, then run the notebook cells in order.
  • Random results? Some quantum samples and ML calculations are intentionally stochastic.
  • Toy DH or Shor circuits? Educational examples illustrate the mathematics; they are not production attacks or fault-tolerant hardware demonstrations.
  • SKR figures? These are outputs of models with assumptions, not deployment guarantees or complete finite-key security proofs.
